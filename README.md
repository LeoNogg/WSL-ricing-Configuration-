# WSL-But-Beauty-

This repository contains my **WSL - Windows Terminal** configuration and ricing setup.

I'm keeping everything here as a backup so I can quickly restore my environment after reinstalling Windows or setting up a new machine. Feel free to use, modify, or adapt anything for your own setup.

## ✨ What's included

- 🖥️ WSL configuration
- ⚡ Fastfetch configuration
- 🔤 Nerd Fonts setup
